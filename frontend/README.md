# LinkSnip

LinkSnip is a full-stack URL shortening and analytics platform that allows users to create, manage, and analyze shortened links.

## 🚀 Live Demo

Backend API: YOUR_BACKEND_URL

## ✨ Features

- User registration and login
- Secure authentication
- Create shortened URLs
- Custom URL aliases
- Link expiration
- View all created links
- Copy shortened URLs
- Deactivate links
- Click analytics
- Clicks over time
- Referrer analytics
- Device analytics
- Browser analytics
- Operating system analytics
- Country analytics
- City analytics
- Responsive design
- Production deployment

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- Axios
- JavaScript
- CSS

### Backend

- Python
- FastAPI
- REST API

### Database

- PostgreSQL

### Deployment

- Frontend: Netlify
- Backend: Render
